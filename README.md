# CareerScout AI

AI agent that finds genuine paid internships and fresher jobs, verifies the
employer and vacancy, filters suspicious listings, and ranks matches to a
candidate profile with evidence.

Final-year B.Tech AIML project.

## Status

Week 1: project setup in progress.

## Planned structure

- `backend/`: FastAPI application, worker and tests
- `frontend/`: React + Vite web app
- `scripts/`: maintenance scripts
- `docs/`: SRS, diagrams and reports
